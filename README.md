# ALALM ELAKHADAR LANDSCAPING L.L.C — GitHub Website

GitHub Pages-ready website for ALALM ELAKHADAR LANDSCAPING L.L.C, Abu Dhabi, UAE.

## Included
- Official company logo supplied by the client
- Supplied 54-page company profile PDF
- All supplied company contact and leadership details
- Landscaping, garden, irrigation, civil, paving/interlock, gravel, plants/shrubs/grass and maintenance services
- Real supplied irrigation and paving/gravel project photographs
- Client list and supplied official links
- Supplier list and supplied official links
- Client/supplier website favicon branding in the logo cards
- Responsive layout, gallery filters, lightbox, WhatsApp enquiry form
- Additional landscaping visuals used as presentation imagery

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main`, folder `/ (root)`.
5. Save and open the generated GitHub Pages URL.

## Notes
The client and supplier cards use the official domains supplied by the company. Their current website/favicons are loaded remotely for branding; if you want fully offline/local logo files, replace the image URLs in `index.html` with downloaded logo assets.
